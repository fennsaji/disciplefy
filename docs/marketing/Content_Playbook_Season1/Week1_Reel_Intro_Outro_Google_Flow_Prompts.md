# Week 1 How-To Reels — Google Flow / Veo Prompts (Intro + Outro)

One generic Intro and one generic Outro, reusable across all 4 Week 1 screen-recording Reels (`Content_Playbook_Season1_Week1.md`). The Disciplefy screen-recording middle section isn't generated — that's the real app capture.

## How to use
1. Paste the **STYLE BLOCK** first, then the Intro or Outro prompt.
2. For the **Outro**, attach the actual Disciplefy logo file as a reference image in Google Flow and reference it as "the attached logo" in the prompt — don't let the model invent its own logo, AI-generated logos/text render unreliably.
3. Keep clips short (3-5s intro, 3-4s outro) — they're bookends around the real screen recording, not the main content.
4. No on-screen text needs to render in the generated clip itself — add each reel's specific hook line as a text overlay in edit (Canva/Premiere/CapCut), same as the rest of the season's assets, for crisp on-brand type. That's how the same generic clips work across all 4 different topics.

---

## 🎨 STYLE BLOCK (prepend to both prompts below)
> Premium, warm, cinematic short video clip for a Christian discipleship app called **Disciplefy**, used as an Instagram Reel intro/outro segment. Portrait **9:16**. Warm, golden-hour or soft window lighting — reverent, peaceful, hopeful, premium. **Slow, intentional pacing**: fade, slow zoom, soft dissolve, gentle light bloom. **No** fast cuts, whip pans, spinning, or aggressive animation. Setting: a quiet home or coffee-shop workspace, warm wood tones, soft natural light, subtle film grain, organic feel — never overly sharp or artificial. **No other apps, phone UI, or on-screen branding besides Disciplefy's own logo where explicitly noted.** Avoid: cheesy stock-photo feel, clip-art crosses, corporate look, garbled text.

> Warm, premium closing card for Disciplefy. Soft cream/warm-gold gradient background with gentle light bloom. **Use the attached logo image** (gold open-book-with-cross icon + "Disciplefy" wordmark) — it gently fades and rises into the center of frame with a soft glow, no harsh motion, keeping the logo's real shape and type intact (don't regenerate or redraw it). Logo only — no additional text needed; the caption already carries "link in bio." Slow fade, 3-4 seconds, reverent and hopeful, premium cinematic pacing — no fast cuts or flashy transitions.

*If Google Flow distorts the attached logo when animating it, fall back to: generate the clip with the reserved empty space and no logo at all, then composite the real static logo file on top in edit — same approach the carousel prompts already use for text ("AI text/logos are unreliable — overlay the real asset in edit").*
