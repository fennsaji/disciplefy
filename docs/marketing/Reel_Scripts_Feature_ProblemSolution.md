# Disciplefy — Marketing Reel Scripts (30–60s)

**20 standalone reels**, 2 recurring characters, problem→solution style.
Each numbered reel is a **separate 30–60 second video** with a timecoded beat sheet.
For Instagram Reels / YouTube Shorts / TikTok. All dialogue **translates cleanly to Hindi**.

## Recurring Characters
- **SARAH** — the seeker / struggler. Voices the problem.
- **DANIEL** — the friend who shows Disciplefy. Warm, never preachy.

## Format key
- `[ ... ]` = visual / camera direction
- `( ... )` = on-screen text caption
- **NAME:** = spoken line
- **0:00–0:05** = timecode for that beat
- **CTA card** = identical closing brand frame (logo + "Link in bio") on every reel

## Universal 5-beat structure (how each reel fills 30–60s)
1. **Hook** (0–5s) — the problem line or a strong visual. Stops the scroll.
2. **Problem build** (5–15s) — make the pain real; add a second beat so it lands.
3. **Solution walkthrough** (15–40s) — Daniel shows the feature; **screen recording does the talking**.
4. **Turn / payoff** (40–52s) — Sarah's transformation; the emotional win.
5. **CTA** (52–60s) — one clear line + CTA card.

## Translation guidelines (English → Hindi)
- Keep every spoken line **≤ 10–12 words**.
- **No puns, rhymes, or idioms** — carry emotion with visuals.
- **On-screen text minimal**, large font, one idea per card.
- Use **universal, everyday phrasing**.
- Keep the **CTA card identical** across languages.
- Film app **screen recordings once**; reuse across reels, swap captions per language.

## Production notes
- **Hook first:** the problem line (or strongest visual) lands in the first 2–3 seconds — even in a 60s reel.
- **Let the app talk:** the 15–40s walkthrough is the heart of each reel; use a clean **real screen recording**, scrolled slowly so viewers can read.
- **Pace for retention:** cut every 2–3 seconds; never hold a static shot longer than ~4s.
- **Reuse footage:** film each app demo once; recut across the POV / Demo / Before-After reels.
- **Consistent CTA card** closes every reel (logo + "Link in bio").
- **Theology-safe** Voice Discipler framing — always "companion, points back to Scripture and community," never a replacement for pastor, church, or Bible.
