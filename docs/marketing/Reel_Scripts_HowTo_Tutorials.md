# Disciplefy — How-To Tutorial Reels (App Walkthroughs)

A user-onboarding / education series: **15 tutorial reels** that teach people how to
navigate the app and use every feature. Separate from the marketing (problem→solution)
set. Each is a **30–60s screen-recording walkthrough** with on-screen step badges.

## Host
- **DANIEL** — friendly guide. Can appear on camera in the intro/outro, or be **voiceover (VO)** over the screen recording. Screen recording is always the star.
- *(Optional)* **SARAH** as the "new user" learning alongside the viewer, for warmth.

## Format key
- `[ ... ]` = screen recording / camera direction
- `(Step 1)` = on-screen step badge
- `( ... )` = on-screen text caption
- **DANIEL:** = spoken line (on camera or VO)
- **0:00–0:05** = timecode
- **End card** = identical closing frame ("Disciplefy — try it free. Link in bio.")

## Tutorial structure (how each fills 30–60s)
1. **Promise** (0–5s) — "Here's how to [do X] in Disciplefy."
2. **Steps** (5–45s) — 3–5 numbered steps, each a real screen action + short VO.
3. **Pro tip** (45–53s) — one power-user tip.
4. **End card** (53–60s) — CTA + what to watch next.

> **Navigation note:** Steps follow the app's current structure — bottom tabs
> **Home · Study (✨) · Topics · Community · Saved**. Confirm exact button labels against
> the live build before final captioning; UI labels may evolve.

## Translation guidelines (English → Hindi)
- Spoken lines **≤ 10–12 words**; step captions **≤ 6 words**.
- **No idioms** — name the action plainly ("Tap the Study tab").
- Keep **step badges as numbers** so they don't need translation.
- Re-record VO in Hindi over the **same screen recording**.

## Production notes
- **Screen recording is the hero** — record clean, high-resolution captures at a calm pace so each tap is visible.
- **Step badges** (Step 1, Step 2…) in a consistent corner; large, readable.
- **Zoom/highlight** the exact button being tapped (circle or tap-ripple).
- **VO over recording** is faster to produce and easy to re-voice in Hindi.
- **Same End card** on every tutorial → "Disciplefy — try it free. Link in bio."
- **Series playlist:** post Tutorial 1 (App Tour) as the pinned/first; the rest as a numbered "How to use Disciplefy" series.
