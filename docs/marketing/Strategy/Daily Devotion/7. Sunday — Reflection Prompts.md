# 🙏 Sunday — Reflection Prompts
*New file — Sunday Reflection didn't exist when this folder was built (Sunday used to be "no public content"). Unlike the other days, Sunday's post recaps *that week's* other 6 posts, so it doesn't need discrete named topics — it needs rotating framing devices. Rotate through these rather than repeating the same recap angle every week.*

1. This Week's One Truth — recap the single biggest lesson from the week
2. Carry It Into Worship — connect the week's theme to today's church gathering
3. Which Day Resonated Most? — poll the audience
4. Memory Verse Check-In — did you keep this week's key verse?
5. Missed a Day? Catch Up — recap + link in bio
6. Invite a Friend to Church Today
7. One Question This Week Raised
8. A Verse Worth Re-Reading
9. What Will You Practice Next Week?
10. Community Shoutout — feature a comment or testimony from the week
11. Prayer for the Week Ahead
12. Rest Before a New Week Begins

**Runway:** 12 prompts ÷ 1/week = 12 weeks before repeating — fine, since these are reusable framings, not one-time topics.
