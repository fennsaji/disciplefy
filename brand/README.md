# Disciplefy Brand Assets

Single source of truth for the Disciplefy mark. Everything shipped in the apps is
generated from the files here — do not hand-edit icons in `frontend/android`,
`frontend/ios`, `frontend/web`, `marketing/public` or `admin-web`.

## Colours

| Token | Hex | Use |
| --- | --- | --- |
| Brand gold | `#E3B154` | The symbol |
| Brand black | `#0B0B0B` | Ground behind the symbol; app icon and splash background |
| White | `#FFFFFF` | Symbol on dark photography, or light-background lockups |

`#E3B154` is the flat gold sampled from the approved artwork. The original render
had a metallic gradient; production uses this single flat value so the mark stays
legible at small sizes and reproduces predictably in print and on the web.

## Files

```
brand/
├── disciplefy-symbol-master.svg   vector master — the source of truth
├── symbol/                        the mark, for documents, web and marketing
│   ├── gold.svg  black.svg  white.svg              (transparent ground)
│   └── gold-on-black.svg  black-on-white.svg  white-on-black.svg
├── app-icon/                      square, safe-zone padded, for launchers
│   ├── gold-on-black.svg          primary app icon
│   ├── black-on-white.svg  white-on-black.svg
│   ├── adaptive-foreground.svg    Android adaptive foreground (transparent)
│   ├── icon-1024.png              flutter_launcher_icons source
│   └── adaptive-foreground-1024.png
├── wordmark/                      "DISCIPLEFY" — Poppins Medium, traced to paths
│   └── wordmark-gold.svg  wordmark-black.svg  wordmark-white.svg
├── lockup/                        symbol + wordmark together
│   ├── stacked-*.svg              symbol above, wordmark below (splash)
│   └── horizontal-*.svg           symbol left, wordmark right (site header)
├── splash/                        artwork the splash generator consumes
└── web/                           favicons, apple-touch-icon, .ico
```

The app-icon variants inset the symbol by 18% (26% for the Android adaptive
foreground) so Android's circular and squircle masks never clip the mark.

## Regenerating the app assets

`frontend/pubspec.yaml` points both generators at `frontend/assets/brand/`, which
is copied from `brand/app-icon/` and `brand/splash/`.

```bash
cd frontend
dart run flutter_launcher_icons        # Android mipmaps + iOS AppIcon set
dart run flutter_native_splash:create  # splash for Android, Android 12+, iOS
```

Web, marketing and admin-web assets are not generated by those tools and are
produced from the SVGs with `rsvg-convert` / ImageMagick.

## Splash sizing

Three different surfaces, three different sizes — they are not interchangeable:

| Surface | Asset | Size |
| --- | --- | --- |
| Android 12+ | `splash-android12-icon.png` + `branding-wordmark.png` | 192dp icon in a 288dp canvas; branding 160dp inside a 200×80dp slot |
| Android ≤11, iOS | `splash-lockup.png` | 168 × 250dp (stacked lockup) |
| In-app loading screen | `frontend/assets/images/splash_screen.png` | Same lockup, transparent, composited on brand black |

Two constraints worth knowing before changing these:

- Android 12+ **masks the splash icon to a circle**. A full-bleed or lockup image
  gets its top and bottom clipped, which is why that surface uses the symbol
  alone on a padded canvas, with the wordmark supplied separately as `branding`.
- Android **stretches the branding image** to its slot. Give that drawable the
  slot's own 200×80dp (2.5:1) aspect with transparent padding, or the wordmark
  is visibly squashed vertically.

The splash is gold-on-black in **both** light and dark mode, so there is no
colour flash when the system theme differs from the app's.

## Usage rules

- Do use gold on black, black on white, or white on dark.
- Do keep clear space around the mark of at least the width of the cross bar.
- Don't stretch, rotate, recolour, add shadows, or place the mark on a busy
  background where the negative-space cross stops reading.
- Don't put the "Disciplefy" wordmark inside the app icon — the symbol stands alone.

## Provenance and known limitations

The master was traced from the approved raster artwork, then cleaned: the glow
halo and the baked-in black rectangle were removed and the outline reduced to two
vector paths. It is faithful to the approved design, but it **reproduces that
artwork's geometry as-drawn** — the slight irregularities in the left-hand shape
and the cross's negative-space relationship were not redrawn. If those are to be
refined, do it in the master here and regenerate; everything downstream follows.

The wordmark is Poppins Medium — the typeface already bundled with the app —
set in uppercase with added tracking, then traced to outlines so it renders
without depending on the font being installed.
